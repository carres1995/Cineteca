Flujos de Sincronización Clave

1. Cambiar filtro en Discover

DiscoverFilters (onChange) → setFilters() → URL query params actualizados → useMovieDiscovery() se re-trigger (por queryKey) → Query fetches → DiscoverGrid se redibuja

2. Agregar película a biblioteca

AddToLibraryButton (click) → useMutation (optimista) → LibraryContext.add() → localStorage se escribe → LibraryGrid + LibraryPage se redibujan
Si falla: revert automático + ErrorState

3. Validación en borde (URL)

DiscoverPage (al montar) → Lee URL: ?genre=99&year=abc → Valida con Zod → Si inválido: fallback a valores por defecto → useMovieDiscovery() recibe valores seguros

Reglas de Arquitectura

  • Domain no importa React. Entidades, policies, schemas viven en TypeScript puro.
  • Presentation no importa Axios. Todo pasa por infrastructure/ → application/ → domain/.
  • Componentes reciben datos por props. No hagan queries dentro de <MovieCard>.
  • Hooks traen datos, componentes los pintan. No mezcles lógica con render.
  • Context solo para estado persistente compartido. Filtros momentáneos van en URL o React Query.
  • URL es el fuente de verdad. Si se puede bookmarkear, va en la URL.
  • Validación en todos los bordes: Red, localStorage, URL.
